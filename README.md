# smallerworld.club

_a place to share your feelings with friends._

## setup

> [!IMPORTANT]
>
> ensure you have [`mise`](https://mise.jdx.dev) installed on your machine.

```bash
# Install dev tools and dependencies:
mise install

# Set up local dev environment:
mise setup

# Run the development server:
mise dev
```
