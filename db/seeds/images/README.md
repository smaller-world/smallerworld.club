# Development world icons

These five PNGs were downloaded once from DiceBear's 10.x Clay API with seeds
`alex`, `blair`, `casey`, `drew`, and `ellis`, at size 256:

`https://api.dicebear.com/10.x/clay/png?seed=alex&size=256`

[Clay by DiceBear](https://www.dicebear.com/styles/clay/) is licensed under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Setup reads these files locally and never contacts DiceBear.
